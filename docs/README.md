# orm docs

The working guide for this package lives in the documentation hub
(`semitexa/docs`), served at `/docs/data/orm-guide`. Relations, querying,
pagination, filtering and schema sync are covered by the other pages in
the `data` section, and every mapping attribute is listed in
`reference/attributes-orm.md`.

`MODULE_STRUCTURE.md` stays here: it is the record of why this package
carries a local extension to the canonical module layout, not something a
consumer needs to read.
